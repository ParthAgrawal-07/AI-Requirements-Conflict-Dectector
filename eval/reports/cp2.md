## 2. Recall by layer — reworded conflicts (component D)

18 pairs written to share little vocabulary: 15 conflicts and 3 look-alike non-conflicts.

| | Pairs |
|---|---|
| Conflicts | 15 |
| … of which **below the similarity threshold** (the filter would never send them to the AI) | **9** |
| Caught by **rule checks** | **12** (all 12 labelled with an expected rule, each by that rule) |
| Missed by the rules (only the AI or a person can catch them: data residency, guest checkout, nightly vs hourly freshness) | 3 |
| Rule false positives on the 3 look-alikes (a valid range, two non-exclusive actors, unrelated actions) | **0** |

By rule: numeric limit 5/5, negation 3/3, exclusive actor 2/2, same condition with different
responses 2/2. Of the 9 conflicts below the threshold, the rules catch 6; the other 3 are the
three "AI or person only" pairs, and all 3 are also below the threshold — which is the case US-56
(raise a concern) exists for.

`tests/integration/test_recall_layers.py` runs the same set through the database path
(`RuleChecker.check_all`) on every CI run: Heet's "done when — rule checks catch the
below-threshold benchmark subset".

## 3. Recall by layer — the planted SRS (component A)

| | Pairs |
|---|---|
| Labelled conflicts | 8 |
| … below the similarity threshold | 6 |
| Caught by rule checks | **2** — REQ-021/REQ-023 (API timeout 2 s vs up to 10 s), REQ-034/REQ-035 (audit logs kept seven years vs deleted after 12 months) |
| Not caught by rules (semantic: encryption vs plaintext, hashing vs viewing passwords, session expiry vs "until logout", concurrency vs "any number", anonymised vs named) | 6 — for the AI, or for a person |
| Rule hits on pairs **not** labelled as conflicts | **0** (of 1,770 pairs) |

**Tuning during the sprint.** The first version of the extractor fired on 13 unlabelled or
non-conflicting SRS pairs and caught none of the 8: it read printed IDs ("REQ-021:") into the
subject, treated every "time out" as a *session* timeout so API, database and upload timeouts
were compared with each other, missed number words ("seven years"), and kept qualifiers in the
subject ("entries older than 12 months"). The fixes (Keval, Heet) are in the Sprint 5 commits; the
reworded set kept its 12/12 and 0 false positives through them.

**Reading.** Rules are precise but narrow: they find contradictions in numbers, "shall / shall
not", exclusive actors and shared triggers. Most conflicts in a real SRS are semantic, so the AI
layer stays the main one, and the rules guarantee that the numeric class is never lost to the
similarity filter.

## 4. AI suggestions (NFR-36) — not yet measured

The flow is built and tested end to end without a model (`tests/api/test_suggestions.py`):
suggestions are generated after a finding is stored, people respond with one of the six
outcomes, the feedback is append-only, and `GET /projects/{p}/suggestions/stats` reports the
outcome distribution per category next to the expert ratings and the p90 latency (target 30 s).

To fill this section at the CP2 review:

1. Seed the demo project and run analysis with `GEMINI_API_KEY` set (suggestions are generated on
   the `suggestions` queue).
2. Two analysts: `python eval/suggestion_rating.py sample --n 30 …`, fill the sheet (1–5 per
   option), `… submit …`.
3. Owners respond to the suggestions on their conflicts through the app during the demo week.
4. `python eval/suggestion_rating.py report …` → outcomes per category, acceptance rate, expert
   mean and share rated 4–5, p90 latency.

Acceptance and correctness are reported side by side because accepting is not proof that a
suggestion was right. The example re-use experiment (`use_feedback_examples`) stays off until
this comparison exists.

## 5. Reproduce

```bash
docker compose run --rm -v "$PWD:/repo" -w /repo backend \
  python eval/recall_by_layer.py --embedder minilm --llm none --json eval/reports/cp2_layers.json
# with a model, once (records replies), then free re-runs:
python eval/recall_by_layer.py --llm live --record eval/reports/cp2_ai.json
python eval/recall_by_layer.py --llm replay:eval/reports/cp2_ai.json
```
