# UI Wireframes

This directory contains the Figma wireframes for the user interface of the **AI Requirements Conflict Detector** project.

## Screens

### 1. Upload Screen

Allows users to upload a Software Requirements Specification (SRS) document for analysis.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/PADr7NlGN7xi5wTPNaxCmE/Upload-Page?node-id=0-1&t=qdo0OrYoofwsK5hk-1
- **Export:** `upload-screen.pdf`



### 2. Findings List

Displays potential conflicts and ambiguities identified during requirements analysis.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/rfcwa3ANROemNzU2DUkluA/Findings--Review-and-Clarification?node-id=1669-162202&t=yUx9A0uHd3gD5eK8-1
- **Key features:** Finding IDs, linked requirements, issue summaries, severity levels, AI confidence scores, review statuses, search, filters, and review actions.
- **Export:** `Findings List-screen.pdf`

### 3. Conflict Review

Allows reviewers to compare potentially conflicting requirements and record a reasoned decision.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/rfcwa3ANROemNzU2DUkluA/Findings--Review-and-Clarification?node-id=1669-162202&t=yUx9A0uHd3gD5eK8-1
- **Key features:** Side-by-side requirement comparison, source references, AI-generated explanations, severity, confidence scores, reviewer notes, and actions to accept, dismiss, resolve, or request clarification.
- **Export:** `Conflict Review-screen.pdf`

### 4. Clarification Screen

Allows reviewers to prepare clarification questions and record responses from requirement owners.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/rfcwa3ANROemNzU2DUkluA/Findings--Review-and-Clarification?node-id=1669-162202&t=yUx9A0uHd3gD5eK8-1
- **Key features:** AI-generated questions, answer fields, requirement owners, supporting source references, affected requirements, previous exchanges, and draft/submission status.
- **Export:** `Clarification-screen.pdf`

- ### 5. Dashboard

Provides an overview of requirement analysis results, helping users monitor findings, prioritise issues, and track items requiring review.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/PFmviC8y2l8PxQbdLDW6kF/Sprint0_dashboard_wireframe?node-id=0-1&t=OrDllI9R4Rz8pfSG-1
- **Key features:** Total findings, pending reviews, high-severity issues, clarification status, issue categories, recent activity, and priority findings.
- **Export:** `Dashboard-screen.pdf`

### 6. Requirements Relationship Graph

Visualises relationships between requirements to help users explore potential conflicts, duplicates, dependencies, and related requirements.

- **Design tool:** Figma
- **Figma link:** https://www.figma.com/design/PFmviC8y2l8PxQbdLDW6kF/Sprint0_dashboard_wireframe?node-id=0-1&t=OrDllI9R4Rz8pfSG-1
- **Key features:** Relationship map, requirement search, issue-type and confidence filters, selected-requirement details, connected requirements, relationship explanations, review status, and links to findings and clarifications.
- **Export:** `Requirements Relationship Graph-screen.pdf`

## Notes

- These wireframes represent the proposed UI design and may evolve during implementation.
- The Figma links are provided for viewing the designs.
- PDF exports are included for convenient access to the designs directly from the repository.
