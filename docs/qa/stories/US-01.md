## 2. Story-Specific Checks
- [ ] PDF, DOCX and plain-text uploads are accepted; a document ID and initial status are shown
- [ ] ReqIF upload behaves as AC-1 states (accepted)
- [ ] Unsupported format is rejected with a message that names the problem
- [ ] Corrupt or empty file is handled without a crash
- [ ] File over the size limit is rejected before any processing starts
- [ ] Busy / uploading state is shown; both drag-and-drop and file picker work
