# Project Documentation

Drop all planning/requirements documents here, e.g.:

- Stakeholder Identification & Elicitation Plan
- Consolidated Requirements Baseline (FR / NFR / Domain Requirements)
- Consolidated Product Backlog (User Stories)
- Sprint Plan
- Project Context Summary
- Lab Assignment submissions
- `architecture-diagrams/` — activity diagrams, pipeline diagrams, etc.

Keep filenames descriptive and prefer Markdown/PDF over .docx where possible, since GitHub renders .md and .pdf inline but not .docx.
